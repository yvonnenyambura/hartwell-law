# Hartwell Law, PLLC

A modern, responsive law firm website built with React and Tailwind CSS. The project showcases a professional digital presence for a fictional law firm based in Charlotte, North Carolina.

## Live Demo

[View Live Website](YOUR_VERCEL_URL)

## Project Overview

Hartwell Law is a multi-page law firm website designed to present legal services, introduce attorneys, build client confidence, and make it easy for prospective clients to get in touch.

The design uses a professional colour palette of midnight navy, antique gold, and ivory to create a polished and elegant visual identity.

## Features

- Responsive layouts for desktop, tablet, and mobile devices.
- Homepage featuring practice areas, firm information, attorneys, testimonials, and FAQs.
- Dedicated practice areas page.
- Attorney directory with interactive profile modals.
- Contact page with a consultation enquiry form.
- Required-field form validation.
- Custom submission confirmation modal.
- Responsive navigation menu.
- Reusable React components.
- Client-side routing between pages.

## Tech Stack

- **React** – Component-based user interface.
- **Vite** – Development server and build tool.
- **Tailwind CSS** – Styling and responsive layouts.
- **React Router** – Client-side navigation.
- **Lucide React** – Icons.
- **Vercel** – Deployment.

## Getting Started

To run the project locally:

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate into the project directory:

   ```bash
   cd hartwell-law
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL provided by Vite in your browser.

## Build

To create a production build:

```bash
npm run build
```

## Design Direction

The website uses a refined visual identity:

- Midnight Navy: `#172D46`
- Antique Gold: `#B69A68`
- Ivory: `#F7F5F0`
- Slate Charcoal: `#30343A`

Typography combines Playfair Display for headings with Inter for body text.

## Project Notes

Hartwell Law, PLLC is a fictional law firm created as a portfolio project.

The contact form currently demonstrates client-side validation and a confirmation modal. It does not connect to a backend or transmit enquiries.
